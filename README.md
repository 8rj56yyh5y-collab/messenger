# Gobsek Chat

Корпоративный мессенджер компании: личные чаты, группы отделов, каналы новостей, аудио- и видеозвонки,
конференции с показом экрана, голосовые сообщения, опросы, напоминания и встроенный ИИ-помощник.
Работает на своём сервере, связан с системой управления **Gobsek** (вход через Gobsek, уведомления из Gobsek в чаты).

Дизайн — как у Telegram: список чатов слева с папками, пузыри сообщений, свайпы и долгие нажатия на телефоне.
Светлая и тёмная тема, 7 цветов акцента, 5 фонов, размер шрифта. Пять языков интерфейса: **українська, русский,
English, Deutsch, Polski**. Встроенная инструкция с поиском (меню ☰ → «Инструкция»). Ставится на телефон и компьютер как приложение.

Стек тот же, что у БХ Учёт и Gobsek Mail: Node.js 22 **без внешних зависимостей** (встроенный SQLite `node:sqlite`,
свой WebSocket), интерфейс на чистом JavaScript без сборки. ИИ — Claude через `@anthropic-ai/sdk` (необязательно).

## Что умеет

| Раздел | Возможности |
|---|---|
| **Чаты** | Личные, группы, каналы (пишут только админы), «Избранное», ИИ-помощник. Папки: Все / Непрочитанные / Личные / Группы / Каналы / Архив. Закрепление чатов, отключение уведомлений на час–навсегда, «пометить непрочитанным», архив, черновики на всех устройствах |
| **Сообщения** | Оформление (`**жирный**`, `_курсив_`, `~~зачёркнутый~~`, `||спойлер||`, код, цитаты, списки), ответы, пересылка, правка (48 ч), удаление у всех, реакции, закреп, упоминания `@логин` и `@all`, галочки «доставлено / прочитано», «кто прочитал» в группах, выделение нескольких сообщений |
| **Файлы** | Фото, видео, документы до 100 МБ (перетаскиванием, из буфера, скрепкой), голосовые с «волной» и скоростью 1×/1,5×/2×, просмотр фото с листанием, вкладки «Медиа / Файлы / Ссылки / Голосовые» |
| **Звонки** | Аудио и видео 1:1, конференции в группах до 12 человек, показ экрана, «поднять руку», реакции в звонке, подсветка говорящего, режим «докладчик», сворачивание звонка, журнал звонков, выбор микрофона и камеры |
| **Полезное** | Опросы (анонимные / открытые, несколько ответов), отложенная отправка, отправка без звука, напоминание о сообщении, статусы (на месте, занят, не беспокоить, отошёл, удалённо, в отпуске), каталог открытых групп, ссылки-приглашения |
| **ИИ (Claude)** | Личный помощник, пересказ чата (непрочитанное или последнее), три варианта ответа по контексту, «улучшить / официальнее / дружелюбнее / короче / подробнее», перевод черновика и любого сообщения |
| **Gobsek** | Вход через Gobsek (SSO, должность и отдел подтягиваются), входящие вебхуки: Gobsek пишет задачи, согласования и протоколы в нужный чат |
| **Администрирование** | Сотрудники (создание, роли, отключение, сброс пароля), приглашения по ссылке, статистика, журнал действий |
| **Безопасность** | Пароли scrypt, cookie HttpOnly, защита от перебора и CSRF, файлы только участникам чата, CSP, медиа звонков — напрямую между участниками (DTLS-SRTP) |

## Быстрый старт

Нужен Node.js **22.13+**.

```bash
npm install            # необязательно: ставит только SDK для ИИ
npm run demo           # демо с сотрудниками и перепиской → http://localhost:3000
```

Демо-вход: `admin` / `demo1234` (у остальных — `olena`, `ivan`, `maria`, `dmytro`, `anna`, `serhii`, `natalia`, `andrii`, `yulia`, пароль тот же).
Откройте два разных браузера (или обычное и приватное окно), войдите разными сотрудниками — и проверьте переписку и звонки.

Рабочий запуск:

```bash
npm start              # http://localhost:3000 — при первом входе мастер создаст администратора
```

На Mac — двойной клик по `start-mac.command`: запустит сервер и откроет браузер.

## Настройка (переменные окружения)

| Переменная | Что это |
|---|---|
| `PORT` | Порт (по умолчанию 3000) |
| `DATA_DIR` | Папка с базой и файлами (по умолчанию `./data`) |
| `ADMIN_LOGIN`, `ADMIN_PASSWORD`, `ADMIN_NAME` | Создать администратора при первом запуске без мастера |
| `COMPANY_NAME`, `APP_NAME` | Название компании (для ИИ и чатов по умолчанию) и приложения |
| `COOKIE_SECURE=1`, `TRUST_PROXY=1` | За HTTPS-прокси (Render, nginx) |
| `MAX_UPLOAD_MB` | Предел размера файла (по умолчанию 100) |
| `EDIT_WINDOW_HOURS` | Сколько часов можно править сообщение (48) |
| `ANTHROPIC_API_KEY`, `AI_MODEL` | Включить ИИ-помощника (модель по умолчанию `claude-opus-5-5`) |
| `GOBSEK_SSO_SECRET` | Общий секрет для входа через Gobsek |
| `GOBSEK_SSO_URL` | Адрес в Gobsek, который выдаёт токен входа (кнопка «Войти через Gobsek») |
| `GOBSEK_URL` | Ссылка «Открыть Gobsek» в меню |
| `GOBSEK_ADMINS_ARE_ADMINS=1` | Администраторы Gobsek становятся администраторами чата |
| `STUN_URLS`, `TURN_URLS`, `TURN_SECRET` | Серверы для звонков. Для звонков через интернет из закрытых сетей нужен TURN (coturn с `use-auth-secret`), как в Gobsek |
| `ICE_SERVERS` | Полный список ICE-серверов в JSON (вместо трёх переменных выше) |
| `CALL_MAX_PEERS` | Максимум участников конференции (12) |

Пример — в `.env.example`.

## Связь с Gobsek

Подробно, с готовым кодом для стороны Gobsek (FastAPI) — [docs/GOBSEK_INTEGRATION.md](docs/GOBSEK_INTEGRATION.md). Коротко:

- **Вход через Gobsek.** Gobsek подписывает короткий JWT (HS256, `aud: "gobsek-chat"`, срок ≤ 10 минут, одноразовый `jti`)
  отдельным секретом `GOBSEK_SSO_SECRET` и открывает `https://chat…/sso/gobsek?token=…`. Мессенджер создаёт или находит
  сотрудника и подтягивает имя, должность и отдел. Основной секрет JWT Gobsek мессенджеру не нужен.
- **Уведомления.** Администратор группы создаёт вебхук (панель чата → Интеграции) и отдаёт адрес Gobsek.
  Gobsek отправляет `POST {title, text, url}` — сообщение появляется в чате от имени бота.

## Звонки

WebRTC «каждый с каждым» — сервер только сводит участников, звук и видео идут напрямую и шифруются.
В одной сети или с белыми IP всё работает сразу. Если сотрудники в разных закрытых сетях (мобильный интернет,
NAT предприятия) — поднимите TURN-сервер (coturn) и задайте `TURN_URLS` и `TURN_SECRET`. Звонки в браузере
требуют HTTPS (на `localhost` — не требуют).

## Развёртывание

**Render.com**: Dashboard → New → Blueprint → этот репозиторий (файл `render.yaml`). Тариф Starter с диском 1 ГБ:
база и файлы сохраняются при перезапусках.

**Свой сервер**: `npm start` за nginx с HTTPS. Для WebSocket в nginx:

```nginx
location / {
  proxy_pass http://127.0.0.1:3000;
  proxy_http_version 1.1;
  proxy_set_header Upgrade $http_upgrade;
  proxy_set_header Connection "upgrade";
  proxy_set_header Host $host;
  proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
  client_max_body_size 110m;
}
```

Резервная копия — папка `DATA_DIR` целиком (`chat.db` + `files/`).
